# komunikasi-clean-architecture

Aplikasi komunikasi real-time dengan pendekatan **Clean Architecture**, dibangun menggunakan **Next.js 15** dan teknologi modern lainnya.

## 🧠 ERD (Entity Relationship Diagram)

[📊 Lihat ERD di dbdiagram.io](https://dbdiagram.io/d/komunikasi-67f935074f7afba184451999)

## 🚀 Instalasi

```bash
# Clone repositori
git clone https://github.com/nama-kamu/komunikasi-clean-architecture.git
cd komunikasi-clean-architecture

# Install dependensi
npm install

# Jalankan development server
npm run dev
```

## ⚙️ Tech Stack

- **Next.js 15**
- **Drizzle ORM**
- **React 19**
- **TailwindCSS v4**
- **shadcn/ui** (UI Components)
- **React Hook Form + Zod** (Form validation)
- **TanStack Table** (Tabel dinamis)
- **Pusher** (Realtime)
- **Framer Motion** (Animasi)
- **Lucide React** (Icons)
- **CUID2**, **Bcrypt**
- **Vitest** + **Testing Library** (Testing)
